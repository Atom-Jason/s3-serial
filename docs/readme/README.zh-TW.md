# S3 Serial

### 把 ESP32-S3 變成隨身攜帶的 Wi-Fi 序列埠與 RS485 調試器。

<img src="../assets/banner.svg" alt="S3 Serial" width="100%" />

同一套離線網頁支援電腦與手機，可設定序列埠、收發 HEX／UTF-8、附加 Modbus CRC、定時傳送及匯出記錄。資源與五種語言皆嵌入韌體，不依賴雲端或外部 CDN。

## 硬體接線

| ESP32-S3 | EKT010 | 本次線色 |
|---|---|---|
| 3V3 | VCC | 紅 |
| GND | GND | **藍** |
| GPIO5 / UART1 TX | RXD，模組輸入 | **黑** |
| GPIO6 / UART1 RX | TXD，模組輸出 | 黃 |

**藍線才是地線，黑線是 RXD。** A+、B− 接從站對應訊號，參考地與獨立供電依從站手冊；B− 不是電源負極。本模組沒有外接 DE/RE，程式不分配方向控制 GPIO。其他線束以絲印與導通確認。[完整接線圖](../HARDWARE.md)。

## 快速開始

安裝並啟用 ESP-IDF v5.5.1，在專案根目錄執行：

```sh
idf.py set-target esp32s3
idf.py build
idf.py -p YOUR_PORT flash monitor
```

將 YOUR_PORT 換成實際埠號。韌體使用 4 MB Flash 位址空間，不依賴 PSRAM。從 USB 啟動記錄取得隨機產生的裝置密碼，連接 S3-Serial-xxxx，開啟 **http://192.168.4.1**。Wi-Fi 與網頁登入使用相同密碼，沒有通用出廠密碼。

取得控制權，依從站手冊核對鮑率與同位檢查，再套用參數；確認生效後儲存至裝置。無已儲存設定時初始為 115200/8N1，不能據此判定從站設定。

## Modbus 範例

僅適用於位址 1、支援從協定位址 0x0000 讀取兩個保持暫存器的從站：

```text
輸入：01 03 00 00 00 02
啟用 CRC 附加後：01 03 00 00 00 02 C4 0B
示範回應：01 03 04 00 7B 00 2D 4A 37
```

若已輸入完整八位元組請關閉 CRC 附加。序列埠同位檢查與訊框 CRC 是不同檢查；UART 傳送完成不代表從站已接收或執行。[Modbus 指南](../MODBUS.md)。

## 無硬體預覽

```sh
python tools/preview.py
```

開啟 http://127.0.0.1:8765/?demo=1；示範不會存取開發板。正常裝置調試使用不含 demo=1 的根路徑。

## 功能與界線

- 1200～115200、自訂鮑率、5～8 資料位元、N/E/O、1/2 停止位元；HEX／UTF-8、CRC、32 筆快捷命令、TXT/CSV 匯出。
- 最多 3 個調試頁面，1 個控制者。15 秒無心跳會撤銷控制權；手機背景執行可能停止定時傳送。
- 定時傳送 20 ms～1 h，不等待從站回應，須考慮從站處理與回應時間。重新連線不自動重送或恢復定時任務。
- RX 為讀取區塊，尚無 RTU 自動分框、接收 CRC 驗證、請求回應配對或回應逾時判斷。
- 瀏覽器歷史上限 5 MiB 原始位元組／20000 筆，裝置 32 KiB／512 筆；淘汰記錄不可匯出，斷電遺失 RAM 歷史。
- 沒有 BLE、OTA 或持久離線採集。適用本機熱點或受信任區域網路。

17 項前端測試、C11 核心測試、韌體建置及檔案校驗已通過；此公開版尚未燒錄實板。真實 RS485 往返與長時間運作仍待驗收。[驗證範圍](../VERIFICATION.md)。
