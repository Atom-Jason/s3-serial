# S3 Serial

### ESP32-S3 を、持ち歩ける Wi-Fi シリアル・RS485 デバッガーに。

<img src="../assets/banner.svg" alt="S3 Serial" width="100%" />

PC とスマートフォンで使えるオフライン Web ワークスペースです。UART 設定、HEX／UTF-8 通信、Modbus CRC 付加、定期送信、ログ出力に対応します。画面と翻訳はファームウェアに組み込まれ、クラウドや外部 CDN は不要です。

## 言語

初回表示はブラウザーの言語によらず **English** です。右上で English、简体中文、繁體中文、日本語、한국어 を選択でき、ブラウザーが選択を保存します。言語変更で再接続、UART 設定の適用、データ送信、入力の消去は行いません。過去のログ、ユーザーが付けたコマンド名、生データ、デバイスの診断文字列は変更しません。詳細な技術文書は現在、簡体字中国語です。

## 配線

| ESP32-S3 | EKT010 | このハーネスの色 |
|---|---|---|
| 3V3 | VCC | 赤 |
| GND | GND | **青** |
| GPIO5 / UART1 TX | RXD、モジュール入力 | **黒** |
| GPIO6 / UART1 RX | TXD、モジュール出力 | 黄 |

**GND は青、黒は RXD です。** A+ と B− を子局の対応信号へ接続し、基準 GND と別電源は子局の説明書に従ってください。B− は電源マイナスではありません。外部 DE/RE ピンはなく、方向制御 GPIO も設定しません。他のケーブルでは表示と導通を確認してください。[配線図](../HARDWARE.md)。

## クイックスタート

ESP-IDF v5.5.1 を導入して環境を有効にし、プロジェクトのルートで実行します。

```sh
idf.py set-target esp32s3
idf.py build
idf.py -p YOUR_PORT flash monitor
```

YOUR_PORT は実際のポートへ置き換えてください。Flash の 4 MB アドレス空間を使用し、PSRAM は不要です。USB 起動ログでランダム生成されたパスワードを確認し、S3-Serial-xxxx に接続して **http://192.168.4.1** を開きます。Wi-Fi と Web ログインは同じパスワードを使い、共通の固定パスワードはありません。

操作権を取得し、子局の説明書に合わせてボーレートとパリティを確認してから設定を適用してください。確認後にデバイスへ保存すると再起動後も保持されます。保存済み設定がない場合の初期値 115200/8N1 は、子局の設定を示すものではありません。

## Modbus の例

子局アドレス 1 が、プロトコルアドレス 0x0000 から保持レジスターを 2 個読み出せる場合の例です。

```text
入力：01 03 00 00 00 02
CRC 付加後：01 03 00 00 00 02 C4 0B
応答例：01 03 04 00 7B 00 2D 4A 37
```

完全な 8 バイトを入力した場合は CRC 付加を無効にしてください。シリアルパリティとフレーム CRC は別の検査です。UART 完了は子局での受信・実行完了を保証しません。[Modbus ガイド](../MODBUS.md)。

## ハードウェアなしで試す

```sh
python tools/preview.py
```

http://127.0.0.1:8765/?demo=1 を開きます。デモは実機にアクセスしません。実際のデバイスでは demo=1 のないルートを使ってください。

## 機能と制限

- 1200～115200、カスタムボーレート、5～8 データビット、N/E/O、1/2 ストップビット、HEX／UTF-8、CRC、32 件のコマンド、TXT/CSV 出力。
- 最大 3 ページ、操作権は 1 ページのみ。15 秒間ハートビートがないと操作権を失います。スマートフォンのバックグラウンド動作で定期送信が停止する場合があります。
- 送信周期 20 ms～1 h。子局の応答は待たないため、処理・応答時間を考慮してください。再接続で自動再送・自動再開は行いません。
- RX は読取ブロックです。RTU 自動分割、受信 CRC 検証、要求・応答の対応付け、応答タイムアウトは未実装です。
- 履歴はブラウザーで生データ 5 MiB／20000 件、デバイスで 32 KiB／512 件まで。削除済み記録は出力できず、電源断で RAM 履歴を失います。
- BLE、OTA、永続的なオフライン収集は未実装です。ローカル AP または信頼できる LAN で使用してください。

フロントエンド 17 テスト、C11 コア、ビルドとファイル検証は成功しています。この公開版はまだ実機へ書き込んでいません。実際の RS485 往復通信と長時間試験は未完了です。[検証範囲](../VERIFICATION.md)。
