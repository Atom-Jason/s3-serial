# 使用指南

## 语言

首次打开默认 English，右上角可选 English、简体中文、繁體中文、日本語、한국어。选择保存在当前浏览器；存储不可用时仍可在本页切换。切换不发送数据、不改变未应用草稿或串口配置。历史日志、用户命令名称与设备原始诊断文字保留原文。

## 连接与控制权

设备默认创建 S3-Serial-xxxx 热点，地址 192.168.4.1。密码由首次启动生成，在 115200 波特率的 USB 日志中查看；业务 UART1 的波特率单独配置。登录后先申请控制权，再配置或发送；最多 3 个调试页面，同时只有 1 个控制者。

心跳每 5 秒发送，15 秒失联会撤销控制权并取消未开始的发送，当前报文可完整发完。手机锁屏或进入后台可能导致心跳暂停。重新连接不自动重发报文，不恢复定时任务。

## 串口参数

波特率常用下拉包含 1200、2400、4800、9600、19200、38400、57600、115200；自定义允许范围内的整数。数据位 5～8、校验 N/E/O、停止位 1/2。目标设备仍须支持相同参数。

修改表单只是待应用草稿；“应用参数”等待设备确认后，顶部与“设备实际”才表示实际生效值。“保存到设备”保存设备当前生效值，不能替代应用步骤。切换参数会短暂暂停接收，并可能丢弃已缓冲数据。正在发送或定时任务运行时不可切换参数。

发送间隔单位为微秒，范围 0～100000，表示本机 UART 发送结束后到下次发送的额外最小间隔；不是从站应答超时，也不是 Modbus 自动分帧参数。

## 发送数据

HEX 每字节两位，可有空白分隔，不接受 0x 前缀。文本以 UTF-8 编码，可选择 CR/LF/CRLF；HEX 模式不会追加文本行尾。单次最终最多 1024 字节，包含可选 CRC。CRC 追加仅支持 8 数据位。

查看“最终字节”后单次发送。“已排队”“正在发送”“UART 已发完”是不同阶段；最后一个不等于对端执行成功。断线前没有得到确认的命令标为未知，不自动重发。

## 定时与快捷命令

设备端定时发送范围 20 ms～1 h，至少满足报文线时间加发送间隔；忙时跳过，不积压补发。启动时冻结最终报文快照，编辑输入不会修改运行中的任务。它不等待从站应答，Modbus 轮询须另行考虑处理时间。

快捷命令最多 32 条，保存在当前浏览器，不是设备 NVS。点击填入发送区；支持 JSON 导入导出，导入会替换列表并提示确认。

## 数据监视与日志

可查看 HEX、文本或两者，按 RX/TX 筛选。二进制在文本中可能出现替换符或可视控制字符，应优先查看 HEX。RX 是软件读取的数据块，可能拆帧或并帧；时间戳不是逐字节硬件时间。

暂停显示仍继续记录；清空只清空当前页面。最多渲染最近 1000 行，浏览器历史限制为 5 MiB 原始字节 / 20000 条，设备历史为 32 KiB / 512 条。淘汰后无法导出已删除记录。TXT/CSV 导出保留 HEX 原始字节。

## 网络与设备

控制者可设置 AP+STA 接入路由器，同时保留热点。路由器网段与 192.168.4.0/24 重叠时停用 STA，保留 AP。手机可能因热点无互联网而切到移动数据或其他 Wi-Fi，出现网页掉线时先确认仍连接设备热点。

设备密码也是热点密码；修改会注销网页会话，可能需要重新连接热点。仅在本地热点或受信任局域网使用。更新固件后 Ctrl+F5 刷新，手机可关闭旧标签页再重新打开。
