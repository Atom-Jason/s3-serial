# S3 Serial v1.0.0

ESP32-S3 Wi-Fi 网页串口 / RS485 调试器首个公开版本。

## 功能

- 离线响应式网页，电脑和手机共用；有密码热点及可选 AP+STA。
- UART1 TX GPIO5 / RX GPIO6，最高 115200，常用及自定义波特率。
- HEX / UTF-8、CRC-16/MODBUS、定时发送、快捷命令、TXT/CSV 导出。
- 1 控制者 + 2 观察者，心跳失联撤销未开始任务，不自动重放发送。
- MIT 许可证、完整中文文档、接线图、电脑与手机视口截图、GitHub CI 配置。

## 已修复

- 波特率下拉被当前输入过滤。
- 固定演示应答 CRC 不正确，改为动态计算并新增演示历史回归。
- 状态接口版本写死，改为读取真实应用版本。

## 使用

首次连接查看 USB 日志中随机生成的设备密码，连接 S3-Serial-xxxx 并访问 http://192.168.4.1。先申请控制权，再按从站手册应用实际串口参数。热点与网页登录密码相同，没有通用出厂密码。

固件使用 4 MB Flash 地址空间、不依赖 PSRAM。独立镜像偏移以包内 flash_args 为准；合并镜像从 0x0 写入并覆盖间隙内的已有 NVS，设备配置可能重置。

## 验证与边界

前端 17 项测试、C11 串口逻辑测试与固件构建校验已执行；当前实板烧录状态以同版本 VERIFICATION.md 为准。界面图为显式演示与手机视口模拟。真实 RS485 往返、快速应答、连续流及两小时运行未完成验收。

当前提供原始串口与 CRC 辅助，不包含完整 Modbus 主站事务、自动分帧或 RX CRC 校验；尚无 BLE、OTA、持久离线采集。定时发送不等待从站应答。
