# 常见问题

### 为什么地址是 192.168.4.1？

这是本项目选择的本地热点静态地址，便于离线直接访问，不是 ESP32 必须使用的地址。手机或电脑须连接该热点，或通过已配置的 STA 地址访问。STA 网段重叠时停用 STA，保留热点。

### 为什么热点显示没有互联网？

调试网页由 ESP32 本地提供，不需要互联网。允许保持热点连接；自动换到其他 Wi-Fi 或移动数据可能使网页失联。

### 为什么没有初始通用密码？

设备首次启动生成随机密码并持久保存。查看 USB 控制台的 Device / Wi-Fi password 行。Wi-Fi 与网页登录共用设备密码；不要把带密码日志上传。

### 改波特率后只有一项可选？

内部联调版本曾使用会按当前输入过滤的 datalist，公开 v1.0.0 已改为完整常用下拉和自定义。更新后强制刷新；页脚会跟随设备状态显示实际版本。

### 修改参数后重启恢复旧值？

先应用、等待设备确认，再保存。仅修改表单不会改变设备；仅应用不跨重启持久化。

### 为什么是乱码？

Modbus 数据包含二进制、控制字节和 CRC，不能把所有字节当作 UTF-8 文本。HEX 是判断字节是否正确的主要依据。文本输入和目标设备字符编码也需一致。

### RX 就是完整 Modbus 帧吗？

不是。RX 当前是软件读取块；可能一帧拆多行或多帧合并。尚未自动分帧和验证应答。

### 为什么发了六字节读请求却没有回应？

01 03 00 00 00 02 尚未含 CRC；勾选 CRC 追加后最终应为八字节。若已输入完整帧则关闭追加。更多原因见 MODBUS.md。

### 定时任务为什么停止？

释放控制权、退出、设备重启或心跳失联都会停止未开始发送。手机后台可能延迟心跳；重连不会自动恢复任务。

### 能用蓝牙或远程互联网访问吗？

当前只实现 Wi-Fi 网页，没有 BLE。服务设计用于本地热点或受信任局域网，不直接提供公网部署方案。

### 能否用于其他板子或转换模块？

需要自行确认 GPIO、供电、电平和方向控制方式。当前仅配置 UART1 TX5/RX6，没有外接 DE/RE GPIO。不能直接将有 DE/RE 的另一种模块按同样软件假定运行。

### ESP32 显示 16 MB，但固件写的是 4 MB？

当前基础分区按 4 MB 编译，只使用这部分地址空间，剩余容量尚未配置使用。此提示本身不表示应用启动失败；以实际启动和服务日志判断。
